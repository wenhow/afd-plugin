# Fixed DSpark target Graph component admission

This increment propagates the retained target shape into explicitly injected
Graph capability construction and binding. Attention derives q=N+1 from its
validated native DSpark config; an explicit different shape is rejected. F
keeps its private config free of speculation and Engram and receives the
immutable target shape from its worker. Missing F shape retains only q1;
binding compares its expected width against the negotiated wire. Eager
capabilities preserve their existing q1 contract regardless of model width.

The shared Graph validator accepts only fixed DSpark with an explicitly
eager draft, adaptive verification disabled and no DSpark PD. Target Graph
still requires FULL_DECODE_ONLY, paired native TP, counts protocol and the
existing model/device/rank/storage constraints. The explicit U2 constructor
compares its original target shape against negotiated capabilities before
native construction. It does not instantiate a drafter on F or alter native
target/draft sampling, Engram producer, KV lifecycle or TP reductions.

The general production V4.1 feature guard is unchanged. These components do
not make normal serving select DSpark Graph. Query codec, native geometry,
cache consumers, target/draft isolation and device results have separate
evidence and must match the exact source snapshot before being combined.

The [independent review](dspark-graph-admission-independent-review-20261110.md)
found no source blocker. Actual A3 dependency execution
[admission-002](a3-dspark-graph-cpu-20261110/admission-002/results/summary.json)
passed 323 cases: runtime config 106, HCCL config 139 and UBatch runner 78,
zero failures/errors/skips. All 21 installed vLLM/Ascend source pins matched.
Native device allocation and model operations remain explicit CPU seams.
Local Windows separately passed 126 with 120 dependency skips.

The preceding admission-001 stopped before pytest: the harness incorrectly
compared a donor AFD connector design file with an installed AFD package.
Its 21 actual upstream pins matched. The donor is now kept as source-only
evidence, while installed-source checks cover the 21 vLLM/Ascend files.
The rejected attempt and all raw bytes remain intact; it is not a test pass.
No package or upstream file changed. The
[admission index](a3-dspark-graph-cpu-20261110/admission-summary.json) keeps
both attempts, exact commands/source identities, JUnit counts and raw hashes.

Cost is one immutable width check during explicit construction/binding and
one additional HELLO field only for q>1 (protocol evidence is separate).
No new per-token buffer, backend or global state is introduced. Remove the
shape handoff when native role isolation supplies a target-only scheduling
descriptor. This is CPU interface evidence, not full-model, NPU or performance
acceptance.
